# 世界观：聊斋宇宙

## 范围声明

本游戏 **只使用聊斋志异及其志怪叙事传统**。所有宿主、场景、妖鬼规则均从此出，不交叉其他神话体系。

## 世界基调

- **时代感**：多为明代市井与荒郊寺观；具体年号可模糊（「明 · 某府」）。
- **志怪日常化**：鬼、妖、狐、夜叉等与人同行于世间，常人或不知、或装作不知。
- **书生叙事**：赴考、借宿、路遇异事是高频入口，与聊斋原著体例一致。
- **因果与情义**：许多故事以情、义、信、贪、惧驱动结局，而非纯打怪。

## 与「系统」并存时的规则（阶段二）

系统不改变聊斋世界本身的物理与志怪规则，仅改变 **宿主在关键时刻能否获得超维指引**：

- 系统对宿主的说话 **不会外泄**——NPC 不会听到「系统」二字或系统内容。
- 宿主在旁人面前若因心声分神，表现为发呆、迟疑、喃喃自语等，由文案处理，但不暴露系统存在。
- 系统可见的天机、轨迹是 **系统特权**，宿主不能自动获知，除非系统在回应中告知。

## 首个故事：聂小倩（原著锚点）

改编自蒲松龄《聊斋志异 · 聂小倩》。初版剧情应尽量遵循原著顺序与关键情节，改编仅做：

- 互动化拆分（选项、节点）
- 现代白话改写
- 篇幅压缩（单局 20–35 分钟）

## 鬼妖层级（写作参考，非战斗数值）

- **游魂 / 怨灵**：如聂小倩，有善恶分化
- **凶煞 / 夜叉**：如姥姥一脉，压迫感来源
- **异人 / 剑客**：如燕赤霞，人间守护者
- **常人**：书生、店小二、家人等
