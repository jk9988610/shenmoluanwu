# 愿景与核心体验

## 一句话

**聊斋志异文字 RPG：先以原著脉络讲清志怪故事，再让「系统」作为宿主心中的共生声音，在求助与危机时必予回应。**

## 游戏类型

- 文字对话 RPG
- 叙事选择驱动
- 宿主与系统「心声式」对话（旁人不可见）

## 题材范围

**仅聊斋志异**（及同源志怪叙事习惯）。不纳入西游记、山海经、历史人物等其他题材。

## 玩家身份

玩家扮演 **系统**——在宿主体内或伴生存在的超维意识，与宿主通过心声交流。

## 核心体验（定稿）

| 体验 | 说明 |
|------|------|
| 原著沉浸 | 初版剧情尽量按聊斋原著走向推进，再在此基础上接入系统 |
| 心声对话 | 宿主与系统交流如同内心独白，周围 NPC 听不见、看不见 |
| 被动联络 | 平时宿主与系统不联系；仅在宿主 **请求帮助** 或 **遭遇危机** 时触发对话 |
| 必予援手 | 宿主请求帮助时，系统 **必须帮忙**；宿主有危机时，系统 **必须帮忙**（玩家从「如何帮」中选择，不能选拒绝） |
| 初遇 | 宿主某次醒来时，系统主动问候并自我介绍，完成第一次认识 |
| 章节串联 | 完成目标或宿主死亡后系统离开，寻找下一位宿主（后续版本） |

## 受众与调性

- 喜欢聊斋、志怪、轻度叙事选择的玩家
- 文风：**现代白话**，易读；场景可带古韵词，但不堆文言
- 平台：**手机横屏**优先

## 开发策略（重要）

```
阶段一（初版）  →  只做剧情，不做系统界面与机制
阶段二          →  在已有剧情节点上插入系统（初遇、求助、危机回应）
```

初版目标是 **可通读的聊斋短篇互动叙事**；系统层是增量，不推翻原著线。
