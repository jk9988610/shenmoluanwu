# 术语表

本文档统一文案、设计与代码中的命名，避免「系统 / 宿主 / 心声」等概念混用。

## 核心角色

| 术语 | 英文（代码用） | 定义 |
|------|----------------|------|
| **系统** | `system` | 玩家扮演的超维意识，存在于宿主感知中，可窥视天机与宿主信息 |
| **宿主** | `host` | 被系统附身的聊斋故事中人物，如宁采臣 |
| **NPC** | `npc` | 故事中的其他角色，如聂小倩、燕赤霞、姥姥 |

## 交互概念

| 术语 | 英文（代码用） | 定义 |
|------|----------------|------|
| **心声** | `inner_voice` | 宿主与系统之间的对话形式；旁人无法感知，如同内心独白 |
| **宿主呼唤** | `host_call` | 宿主主动向系统请求帮助时触发的对话节点 |
| **危机** | `crisis` | 宿主生命或主线存亡受到直接威胁的时刻；系统必须帮忙 |
| **系统初遇** | `system_awakening` | 宿主某次醒来时，系统首次问候并自我介绍 |
| **系统回应** | `system_response` | 玩家（系统）在呼唤/危机节点选择的帮助方式 |
| **日常静默** | `idle_contact` | 无呼唤、无危机时，宿主与系统不主动联络的状态 |

## 叙事与数据

| 术语 | 英文（代码用） | 定义 |
|------|----------------|------|
| **叙事节点** | `narrative_node` / `event` | 一段场景描写、对话与选项的集合 |
| **剧情选项** | `story_choice` | 宿主在世界上采取的行动（开门、逃走、对话 NPC 等） |
| **天机** | `tianji` | 系统可见的「将发生的事」预览，宿主默认不知 |
| **轨迹** | `timeline` | 宿主过去人生节点摘要 |
| **终局目标** | `final_goal` | 系统附身该宿主时要完成的最终任务（阶段二及以后强调） |
| **撤离** | `departure` | 目标完成或宿主死亡后，系统离开宿主 |

## 开发阶段

| 术语 | 定义 |
|------|------|
| **阶段一：纯剧情** | 无系统 UI，仅原著向互动叙事 |
| **阶段二：接入系统** | 在阶段一节点上增加初遇、心声、求助/危机回应 |

## 禁止混用的说法

- 不说「宿主不知道系统」——宿主知晓系统，但交流仅限心声。
- 不说「系统可以拒绝帮忙」——请求与危机时 **必须帮**，玩家只能选择 **怎么帮**。
- 不说「系统随时和宿主聊天」——平时 **不联系**，除非触发呼唤或危机。
