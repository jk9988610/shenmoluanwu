# UI 规范：手机横屏

## 目标设备

- **主目标**：手机横屏（逻辑宽约 640–900px，高约 360–430px）
- **次目标**：桌面浏览器同比例缩放，居中显示
- **安全区**：适配 `env(safe-area-inset-*)`（刘海 / 圆角）

## 阶段一布局（纯剧情）

```
┌────────────────────────────────────────────────────────────┐
│  兰若寺 · 雨夜                              [进度 · 可选]   │  顶栏 44px
├────────────────────────────────────────────────────────────┤
│                                                            │
│  【叙事区 ~70% 高度】                                       │
│  场景描写 + NPC 对话 + 宿主对外台词                         │
│                                                            │
├────────────────────────────────────────────────────────────┤
│  【选项区】  [ 选项 A ]  [ 选项 B ]  [ 选项 C ]            │  min 56px 触控
└────────────────────────────────────────────────────────────┘
```

- 无左侧宿主条、无系统面板、无心声层。
- 顶栏：地点 / 时间；可选章节进度点。

## 阶段二布局（接入系统）

```
┌────────────────────────────────────────────────────────────┐
│ ◈ 系统   兰若寺 · 雨夜    宁采臣    [天机] [轨迹] [档案]   │
├──────────┬─────────────────────────────┬───────────────────┤
│ 宿主     │ 叙事区                       │ 心声区（条件显示） │
│ 摘要     │ 外在场景与 NPC               │ 仅 hostCall/初遇  │
│ ~22%     │ ~48%                         │ ~30%              │
├──────────┴─────────────────────────────┴───────────────────┤
│ 剧情选项（宿主行动）                                        │
└────────────────────────────────────────────────────────────┘
```

### 心声区显示规则

| 条件 | 心声区 |
|------|--------|
| 日常节点 | **隐藏**或折叠为窄条 |
| `systemAwakening` | 显示，初遇样式 |
| `hostCall` | 显示，宿主求助 + 系统回应选项 |
| `crisis: true` | 显示，危机样式（描边脉动、背景略红） |

**平时宿主与系统不联系** → 心声区默认不占主视觉。

## 视觉区分

| 类型 | 样式建议 |
|------|----------|
| 场景描写 | 米白底 `#f5f0e8`，深灰字 `#1c1917` |
| NPC 对话 | 角色名 + 引号台词，左侧色条区分角色 |
| 宿主对外台词 | 略浅背景，标记「宁采臣」 |
| 心声（宿主） | 斜体或「·」前缀，青灰 `#5eead4` 系 |
| 心声（系统） | 磷绿或青 `#4ade80`，带 `◈` 图标 |
| 系统回应按钮 | 全宽列表项，明确是「你怎么帮」 |

旁人 **不会看到** 心声——UI 上心声始终在「心声区」，与 NPC 对话区分离，强化元认知。

## 系统回应 UI（必帮）

- 展示 `hostText` 后，列出 `responses[].label`。
- **不得**出现灰色不可点项「拒绝」。
- 选中后展示 `systemText` + 可选 `hostReply`，再回到叙事 / 剧情选项。
- 危机时限制选项数量 2–3 个，文案更短。

## 天机 / 轨迹 / 档案

- 顶栏按钮打开 **抽屉**（自右侧滑入，占宽 40%），避免挡叙事。
- 天机：列表 bullet，系统专属。
- 轨迹：竖时间轴，过去节点灰显。
- 档案：姓名、身份、标签、终局目标。

## 配色

| 用途 | 色值 |
|------|------|
| 页面底 | `#1a2421` |
| 叙事纸面 | `#f5f0e8` |
| 强调 / 系统 | `#4ade80` |
| 危机 | `#f87171` 点缀 |
| 分隔线 | `#3f4f46` |

## 字体与排版

- 正文：`16px`–`18px`，行高 `1.6`
- 心声：`15px`–`16px`，行高 `1.5`
- 选项按钮：最小高度 `48px`，字号 `16px`
- 中文字体栈：`"PingFang SC", "Noto Sans SC", system-ui, sans-serif`

## 触控与无障碍

- 所有可点区域 ≥ 44×44px
- 选项不仅靠颜色区分，必有文字标签
- 支持对话历史回看（阶段二可选）
- `prefers-reduced-motion` 时关闭危机脉动

## 响应式

```css
/* 主体验区间：横屏手机 */
@media (orientation: landscape) and (max-height: 500px) { ... }

/* 竖屏提示 */
@media (orientation: portrait) {
  /* 显示「请旋转设备至横屏」遮罩 */
}
```
