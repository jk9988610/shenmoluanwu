## P0：聂小倩（宁采臣）— 详细拆分

### 原著锚点顺序（不可乱序）

1. 赴考途中 / 至兰若寺
2. 借宿，知燕赤霞在寺
3. 小倩夜警告（勿开厢门、勿饮血食）
4. 小倩再访，宁拒金
5. 夜叉祸，燕赤霞斩妖
6. 小倩诉身世、求携骨灰
7. 脱离姥姥控制，离寺
8. 结局（归家 / 相伴 — 可压缩）

### 阶段二：系统接入点

| 类型 | 建议节点 | 宿主说什么（方向） |
|------|----------|-------------------|
| **初遇** | `wake_in_temple` 或 `prologue_road` 次日晨 | 系统自我介绍（唯一系统主动） |
| **请求** | `assign_room` | 「这异响是什么？我能住吗？」 |
| **请求** | `night_knock` | 「有人敲门，开不开？」 |
| **请求** | `gold_offer` | 「这银子能拿吗？」 |
| **危机** | `yaksha` | 「夜叉进来了！」 |
| **请求** | `xiaqian_truth` 前 | 「她到底是不是鬼？」 |
| **危机** | `final_escape` | 「逃不掉了，怎么办！」 |

日常节点（如 `hear_yan` 闲聊） **不** 设 `hostCall`。

### 系统回应设计原则（本线）

- 夜叉、脱身：**危机必帮**，选项为立即行动（躲哪、往哪跑、找谁）。
- 敲门、银子：**请求必帮**，选项为告知风险 / 明确行动。
- 所有选项帮助力度可不同，但不出现拒绝。

| `ending_bad_temple` | 宁死于寺中 |
| `ending_bad_escape` | 脱身失败（可选） |

## P1–P3 简述（仅立项）

### 画皮 · 王生

- 悬疑：宿主请求系统辨别妻子真伪。
- 危机：剖开画皮现鬼形瞬间。
- 初遇：王生某夜醒来。

### 婴宁 · 王子服

- 请求：如何接近婴宁、如何应对母亲反对。
- 危机：山中迷路或妖物现身（改编尺度需谨慎）。
- _tone：轻松转悲。

### 促织 · 成名

- 请求：如何在限期内找到促织。
- 危机：官府逼缴、父亲受累。
- _tone：压迫、窒息。

## 写手产能估算（技术向）

- 单线阶段一：约 12–18 节点 × 200–400 字/节点 ≈ 3000–6000 字叙事
- 阶段二增量：每呼唤点 3 回应 × 50 字 + 初遇 200 字
- 建议先 **竖切**：节点 1–7 可玩 demo，再补全后半
