# 宿主设计模板

复制本模板创建新宿主（聊斋篇目）。阶段一填「纯剧情」列，阶段二补系统字段。

---

## 基本信息

| 字段 | 内容 |
|------|------|
| 宿主 ID | `ning_caichen` |
| 篇目 | 《聂小倩》 |
| 宿主名 | 宁采臣 |
| 身份 | 赴考书生 |
| 时代 | 明 · 某府（可模糊） |
| 标签 | `#书生` `#赴考` `#守义` |

## 原著摘要（3–5 句）

宁采臣夜宿兰若寺，遇聂小倩示警，拒夜叉之祸；后经燕赤霞相助，知小倩为鬼，助其携骨灰脱离妖控制，终与之相伴。

## 系统终局目标（阶段二及以后）

**让宿主活着离开兰若寺，并携小倩（骨灰）脱身。**

次要（可选）：结识燕赤霞并得其认可。

## 系统初遇（阶段二）

| 字段 | 内容 |
|------|------|
| 插入节点 ID | `wake_in_temple`（建议，待剧情拆分后定稿） |
| 醒来情境 | 宁采臣在兰若寺（或前站客栈）醒来，昨夜风雨或路途疲惫 |
| 系统问候要点 | 问候 → 自称「系统」→ 说明心声交流、旁人听不见 → 极简「危急时我会帮你」 |
| 宿主反应 | 惊疑、压低心声回应一句，不展开长聊 |
| 初遇后 | 回到日常静默，直到第一次 `host_call` |

## 轨迹（系统可见，阶段二 UI）

| 顺序 | 节点 | 摘要 |
|------|------|------|
| 1 | 童年 | 寒门读书 |
| 2 | 屡试 | 三番不第，仍欲赴考 |
| 3 | 启程 | 只身带行囊赴考路 |
| 4 | 当日 | 雨夜至兰若寺下 |

## 天机预览（系统可见，勿默认告知宿主）

- 寺中另有剑客燕赤霞
- 夜叉一脉盘踞此寺
- 聂小倩非生人，却欲救宁

## 节点地图（阶段一必填）

| 节点 ID | 原著锚点 | 阶段一剧情选项概要 | host_call（阶段二） | crisis |
|---------|----------|-------------------|---------------------|--------|
| `prologue_road` | 赴考路 | 是否连夜赶路 | — | — |
| `temple_arrival` | 至兰若寺 | 叩门借宿 | 可选：请求（寺是否可住） | — |
| `assign_room` | 分配厢房 | 东厢 / 西厢 | 请求：异响 | — |
| `meet_xiaqian_warn` | 小倩初夜警告 | 信 / 疑 | — | — |
| `night_visit` | 小倩访 | 拒金 / 问来历 | 请求：是否开门 | — |
| `yaksha_attack` | 夜叉夺门 | 躲藏 / 叫喊 | 危机：必帮 | ✅ |
| `meet_yan` | 燕赤霞 | 交谈求教 | 请求：是否求助 | — |
| `xiaqian_truth` | 小倩坦白 | 承诺助其 | — | — |
| `escape_final` | 脱身 | 逃 / 战 / 智取 | 危机：必帮 | ✅ |
| `ending_home` | 归乡结局 | 结局分支 | — | — |

（节点 ID 与数量在实现时可增删，但锚点顺序不变。）

## 结局设计

| 结局 ID | 条件概要 | 简述 |
|---------|----------|------|
| `ending_together` | 主线完成 | 宁与小倩脱身（原著向） |
| `ending_ning_dead` | 危机选错或剧情杀 | 宁死于寺（坏结局） |
| `ending_xiaqian_only` | 宁活、小倩未脱（可选） | 悲剧向，非首版优先 |

## 数据目录约定

```
src/data/hosts/ning_caichen/
├── profile.json      # 档案、目标、标签
├── timeline.json     # 轨迹
├── events.json       # 或 events/*.json 分文件
└── notes.md          # 写手备注，不进游戏
```
